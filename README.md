## 🌟 Tentang Proyek

Repositori ini memuat digitalisasi lengkap dan teks terbuka (open text) dari **Kitab Al-Khulashah** susunan Guru Mulia **Al-Habib Umar bin Hafidz**. Naskah ini mencakup amalan dzikir, doa, wirid, qasidah, ratib, dan hizb yang bersumber dari Rasulullah ﷺ dan para Salafus Shalih mulai dari bangun tidur, fajar, dhuha, dzuhur, ashar, maghrib, isya, hingga adab sebelum tidur, serta amalan khusus malam dan hari Jum'at.

Tujuan repositori ini adalah:
1. **Teks Terbuka & Siap Diedit:** Menyediakan teks Arab berharakat lengkap dan terjemahan bahasa Indonesia dalam format digital yang mudah dibaca, dikoreksi, dan disunting.
2. **Aplikasi Interaktif:** Menyertakan aplikasi web modern berbasis React + TypeScript dengan fitur pembaca, live editor, tasbih counter, pencarian instan, dan ekspor markdown.
3. **Kolaborasi GitHub:** Membuka kesempatan bagi santri, asatidz, dan kontributor di seluruh dunia untuk mengoreksi harakat (tashkeel), menyempurnakan terjemahan, dan memperkaya catatan kaki.

## 🚀 Menjalankan Aplikasi Secara Lokal

Proyek ini dibangun menggunakan Vite, React 19, TypeScript, dan Tailwind CSS:

```bash
# 1. Clone repository
git clone https://github.com/USERNAME/al-khulashah.git

# 2. Masuk ke direktori
cd al-khulashah

# 3. Install dependencies
npm install

# 4. Jalankan dev server
npm run dev
```

Buka peramban Anda di `http://localhost:3000`.

## 🛠️ Panduan Push ke GitHub Repository (Branch main)

Jika Anda ingin mengunggah codebase ini ke akun GitHub pribadi atau organisasi:

```bash
# 1. Inisialisasi git jika belum ada (proyek ini sudah diinisialisasi)
git init

# 2. Tambahkan remote repository GitHub Anda:
git remote add origin https://github.com/USERNAME/al-khulashah.git

# 3. Pastikan branch utama bernama main:
git branch -M main

# 4. Stage seluruh file dan buat commit:
git add .
git commit -m "feat: inisialisasi teks digital lengkap Kitab Al-Khulashah dan aplikasi reader"

# 5. Push ke GitHub:
git push -u origin main
```
